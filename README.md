# 🕷️ Spider-Man: Interactive 3D Game

An immersive, self-contained web experience featuring a low-poly 3D model of Spider-Man. This project renders the classic superhero in a browser using Three.js and includes basic animations and interactive controls.

## 📜 Description

This project is a single HTML file that brings a 3D Spider-Man model to life directly in your browser. The GLB (GL Transmission Format Binary) model is embedded as a Base64 string within the file, making it completely self-contained and easy to run without external asset dependencies.

It uses **Three.js** for 3D rendering and the **GLTFLoader** to parse and display the model. The application includes the model's built-in "Idle," "Run," and "Jump" animations, which are played in a loop.

## ✨ Features

- **Low-Poly Spider-Man Model:** A stylized, low-polygon 3D model of Spider-Man.
- **Multiple Animations:** Includes "Idle," "Run," and "Jump" animations for dynamic movement.
- **Fully Self-Contained:** The entire model is embedded in the HTML file. No external files or server required.
- **Responsive Design:** The canvas automatically resizes to fit the browser window.

## 🛠️ Tech Stack

- **Three.js:** A powerful 3D graphics library for the web.
- **HTML5 / CSS3 / JavaScript:** The core technologies for structure, styling, and logic.
- **GLTF (GL Transmission Format):** The modern standard for 3D assets on the web.

## 🚀 Getting Started

To run this project, you don't need any special setup. Simply open the HTML file in a modern web browser that supports WebGL.

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox, Safari).
